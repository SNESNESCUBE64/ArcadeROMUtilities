# ArcadeROMUtilities
This contains utilities that I have had to write for Free Play or Other Mods. These were mainly used for patching checksums or encrypting or decrypting ROMs. 

## Tools / Function Description
### Dig Dug Checksum Patch Utility
Calculates and appends the recalculated checksums to the correct ROM. Useful if you are editing ROM binaries.

### Eyes Encryption Utility
This tool was used to encrypt and decrypt the ROM data. When you decrypt the data, you can then see the binaries as the CPU sees it. This is great for editing ROM data for mod purposes. It can be used for encrypting other ROM sets to run on Eyes hardware potentially.

### Pacman Plus Encryption Utility
This tool was used to encrypt and decrypt the ROM data. When you decrypt the data, you can then see the binaries as the CPU sees it. This is great for editing ROM data for mod purposes.

### Popeye/Sky Skipper Plus Encryption Utility
This tool was used to encrypt and decrypt the ROM data. When you decrypt the data, you can then see the binaries as the CPU sees it. This is great for editing ROM data for mod purposes. Works with both Popeye and Sky Skipper ROM sets.
